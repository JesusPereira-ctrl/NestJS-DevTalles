## Install NodeJS

- [Node](https://nodejs.org/es/)

## Install Yarn

```bash
npm install --global yarn
```

## Install Docker

- [Docker](https://docs.docker.com/engine/install/)

Download images of Mongo 5.0.0 and Postgres 14.3

```bash
docker pull mongo:5.0.0
docker pull postgres:14.3
```
